# OnceLang (单读单写语言) 🧨

> "集百家之短，成一家之言。变量是一次性的，默认值是永恒的；你敢用，我就敢销毁。"

OnceLang 是一门极致硬核的实验性编程语言。它拥有 C 语言的语法皮囊、纯二进制的内存视角，以及一门极其反人类的底层哲学——**单读单写（One-Read-One-Write）**。

## 🧠 核心哲学

1. **一切皆二进制**：底层没有类型，只有 `bytearray`。你看到的是数字、字符还是浮点，完全取决于你用哪个解释器去解码它。
2. **单读单写**：普通变量写一次、读一次，读完即焚。如果你敢读第二次，它会无情地返回默认值 0，甚至直接把你定义的变量删掉。
3. **分叉续命**：`a, b = a`。想活过两次运算？把它劈成两半！一半拿去用，另一半传宗接代。
4. **堆的绑定与扩容**：`createheap` 只在创建时绑定变量。堆的生命周期只看初始绑定变量，变量死绝，堆立刻释放。堆支持 `handle[offset]` 越界扩容，扩容时会销毁旧堆、重建新堆，完美继承句柄。
5. **绝对容错**：不管代码写得多离谱，只要还能解析出一星半点，就不报错。遇到无法解析的语法，原样打印，继续往下执行。

## 🛠️ 运行方式

```bash
# 正常运行（纯净输出）
python oncelang.py run cases/hello.once

# 打开调试模式（观赏变量被屠杀的日志）
python oncelang.py run cases/hello.once --debug
