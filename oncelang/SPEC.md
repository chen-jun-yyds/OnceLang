# OnceLang 语言规范 v1.0

## 1. 词法结构
- 使用 `;` 作为语句结束符。
- 使用 `{ }` 作为作用域块。
- 支持 `//` 单行注释。

## 2. 类型系统
- **无类型**。所有数据在最底层都是 `bytearray`。
- 字面量：
  - 十进制数字：占 4 字节（32位小端序）。
  - 十六进制数字 `0x...`：占 4 字节。
  - 字符串 `"..."`：直接转 UTF-8 编码的字节流。

## 3. 变量绑定（单读单写）
- 每个变量拥有“写票”和“读票”各一张。
- 一旦被读取，变量立即从符号表销毁，并释放其拥有的堆句柄。
- 读取未声明或已销毁的变量，返回 4 字节全零。
- `a, b = expr;` 语法为分叉复制：求值 `expr` 一次，将结果复制给 `a` 和 `b`。

## 4. 堆内存管理
- `(createheap)(句柄, 大小)`：创建堆，并将接收变量记为“初始绑定”。
- 堆的生命周期只与初始绑定变量相关。初始绑定全部销毁，堆自动释放。
- `(heap)var`：读取变量指向的堆数据。
- `handle[index]`：读写堆内的 4 字节数据。若越界写入，自动销毁旧堆并创建新堆，原堆的初始绑定关系无缝继承给新堆。

## 5. 内置解释器
解释器只能用来“读取视图”和“解码数据”，不会修改底层字节。
- `(int)`, `(float)`, `(bool)`, `(char)`, `(string)`, `(raw)`

## 6. 错误恢复机制
- 解析器遇到无法解析的语句时，不中断执行。
- 解析器会向后寻找 `;`、`}` 或换行符，将这段非法源码包裹成 `ErrorNode`。
- 运行时遇到 `ErrorNode` 时，将其原样打印到标准输出，并继续执行后续代码。
